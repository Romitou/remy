# 🐀 Rémy

Rémy *(from the movie Ratatouille)* is a Discord bot offering its users a modern way to receive notifications when a table becomes available in the restaurants of Disneyland Paris parks and hotels.

Using the [DisneyTables](https://github.com/Romitou/DisneyTables) project specially created for this purpose, users can manage their alerts via the bot and receive messages when a notification is generated by DisneyTables.

**Want to see it in action?** Go to [this Discord server](https://discord.gg/disneyland-paris-notifications-et-entraide-899677077287075930), dedicated to notifications and help around Disneyland Paris.

## 🚀 Features

- 📬 Real-time notifications for restaurant availability
- 🔔 Custom alerts based on date, party size, and meal period
- 🤖 Modern Discord.js v14 with Sapphire Framework v5
- 📊 Daily reports and statistics
- 🔄 Automatic reconnection for Redis and API
- 🛡️ Error tracking with Sentry
- 📝 Structured logging with Pino
- 🐳 Docker support for easy deployment

## 📋 Prerequisites

- Node.js 20.x or higher
- Yarn package manager
- Redis server
- DisneyTables API instance

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/Romitou/Remy.git
cd Remy
```

2. Install dependencies:
```bash
yarn install
```

3. Copy the environment template and configure:
```bash
cp .env.example .env
```

4. Edit `.env` with your configuration (see Environment Variables below)

## 🔧 Environment Variables

Create a `.env` file with the following variables:

- `DISCORD_TOKEN` : the token of your Discord bot
- `BASE_API` : the API address of your DisneyTables instance
- `WEBSERVER_TOKEN` : the DisneyTables API authentication token
- `REDIS_URL` : the address to your Redis server (e.g., `redis://localhost:6379`)
- `REDIS_PASSWORD` : (optional) password for Redis authentication
- `SENTRY_DSN` : (optional) the DSN address to your Sentry configuration
- `NODE_ENV` : environment mode (`development`, `production`, or `test`)
- `LOG_LEVEL` : logging level (`fatal`, `error`, `warn`, `info`, `debug`, `trace`)
- `OWNER_ID` : Discord user ID to receive daily reports
- `CHANNEL_ID` : Discord channel ID for the onboarding message
